# 系列大纲

主线比喻：**Git = 游戏存档系统**。每集都围绕“存档 / 读档 / 多周目 / 云存档 / 联机”展开。
每集结构：冷开场（大肥鱼遇到麻烦）→ 片头 → 每个知识点一问一讲 → 速查复习 → 实战连贯操作 → 下集预告 + 三连。
目标时长每集 4–5 分钟，语速快、衔接少。讲师固定为 GitHub娘，学生是大肥鱼；从第3集起，图库里的其他 AI 娘组成“AI 分工小队”，每人负责演示一个知识点或一个典型坑。

## 第4集《Git 后悔药大全》（已完成，详见 `第4集/策划.md`）

主题比喻：**Git 药房**，每种撤销手段是一颗不同颜色的“后悔药”胶囊。

| 知识点 | 演示角色 | 命令 |
|---|---|---|
| 改上一次提交 | Gemini（说明又写成 2024） | `git commit --amend -m`、`--amend --no-edit`；只改没 push 的 |
| 收起半成品 | 千问（紧急任务） | `git stash`、`stash pop`、`stash list`、`-u` |
| 撤回提交 | 豆包（提交太碎） | `git reset --soft HEAD~3`、默认 `--mixed`；口诀“soft 留暂存，mixed 留工作区，hard 全清空” |
| 危险的 hard 与 revert | Grok（`reset --hard` 退过头） | `reset --hard` 清掉未提交改动；已 push 用 `git revert` |
| 找回提交 | Kimi（翻日记） | `git reflog`、`reset --hard 编号`、`git branch rescue 编号`；救不了没提交的改动 |
| 常见报错急救 | Claude（先读报错） | 本地改动会被覆盖 / detached HEAD / not a git repository |
| 实战 | 大肥鱼的白饭页 | amend → stash → `switch -c` → pop → commit → `reset --hard` 误操作 → reflog 找回 |

## 番外1《Git 小技巧》（已完成，详见 `番外1/策划.md`）

主题比喻：**打开工具箱**。只有 GitHub娘和大肥鱼两人，2:20。

| 技巧 | 命令 |
|---|---|
| 设身份 | `git config --global user.name / user.email`；去掉 `--global` 只改当前仓库；`git config --list` |
| 别名 | `git config --global alias.st status`；`lg` = `log --oneline --graph --all` |
| 看改动 | `git diff`、`--staged`、`--stat`、`git diff v1.0 v1.1` |
| .gitignore 不生效 | `git rm -r --cached`、`git check-ignore -v`、GitHub 的 .gitignore 模板 |
| 实战 | 白饭页：设身份 → 起别名 → 补救 node_modules → `diff --staged` 后提交 |
