# 系列大纲

主线比喻：**Git = 游戏存档系统**。每集都围绕“存档 / 读档 / 多周目 / 云存档 / 联机”展开。
每集结构：冷开场（大肥鱼遇到麻烦）→ 片头 → 每个知识点一问一讲 → 速查复习 → 实战连贯操作 → 下集预告 + 三连。
目标时长每集 4–5 分钟，语速快、衔接少。讲师从 GitHub娘 开始，之后由图库里的 AI 娘轮换。

## 第1集《Git 入门：存档、读档、平行世界》（已完成）

| 部分 | 知识点 | 命令 |
|---|---|---|
| 引入 | 为什么不用“最终版2.docx” | — |
| 存档 | 安装与配置 | `git version`、`git config --global user.name / user.email` |
| | 创建仓库 | `git init`、`.git/` |
| | 三个区域 | 工作区 → 暂存区 → 仓库 |
| | 查看与暂存 | `git status`、`git diff`、`git add 文件 / .` |
| | 提交存档 | `git commit -m`、哈希值、写清楚说明 |
| | 查看历史 | `git log`、`--oneline`、HEAD |
| 读档 | 撤销没存的改动 | `git restore 文件`、`git restore --staged 文件` |
| | 找回旧存档 | `git restore --source=编号 文件`、`git revert 编号`；警告 `reset --hard` |
| 平行世界 | 开分支 | `git branch`、`git switch`、`git switch -c` |
| | 合并 | `git merge`（快进）、`git branch -d` |
| | 冲突 | 冲突标记、手动选择、add + commit |
| 复习 | 存档循环 + 读档三招 + 分支三步 | — |
| 实战 | 从零完整走一遍 | `mkdir` → `init` → `add .` → `commit` → `switch -c` → `commit` → `switch main` → `merge` → `log --oneline --graph` |

## 第2集《GitHub 云存档》（策划中，详见 `第2集_策划.md`）

- 冷开场：电脑坏了 / 换电脑，存档全没了
- 注册 GitHub、新建仓库
- `git remote add origin`、`git push -u origin main`
- 换台电脑：`git clone`
- 两台电脑同步：`git pull`
- 登录认证（简单带过：浏览器授权 / 令牌）
- 预告：和别人一起写

## 番外候选

- `git stash`：临时收起改动
- `git tag`：给版本打标签
- `git commit --amend`：修改上一次的说明
- 常见报错急救包
