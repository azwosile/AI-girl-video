> 状态：**策划 + 台词初稿**（2026-10-25）。台词的唯一来源是 `ep3/_gen_script.py`，运行后生成 `ep3/script.json`（朗读稿）和 `ep3/subtitles.json`（字幕稿）。
> 讲师仍是 **GitHub娘**；组长是 **大肥鱼**；其他 AI 娘组成 **AI 分工小队**，每人的性格取自 B 站等社区对该模型的印象，并且每人负责演示一个协作知识点或一个典型坑。

## 7. 工程与流水线

1. **目录**：`ep3/` 结构同 `ep2/`：`_gen_script.py`、`script.json`、`subtitles.json`、`tts_gen.py`、`vo/`、`web/`。
2. **引擎**：从 `ep2/web/engine.js` 复制与集数无关的部分（含第2集新增的浏览器、云朵、两台电脑组件），再接本集 `TEXT` / `PLAN` / `SC.*`。第1、2集不改动。
3. **多角色**：`SPR_NAMES` 增加 6 人的差分；`PLAN` 里的说话人按 ID 首字母映射（Q/C/M/X/B/K）。字幕颜色每人一色，取各自形象的主色。
4. **prep.py**：`TEMPO` 增加小队的键（建议统一 1.1，生成后按听感微调）。
5. **build / render / mix**：从 ep2 复制，只改成片名 `AI娘Git课_第3集.mp4`。片尾曲继续用《花の塔》。
