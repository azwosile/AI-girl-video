## 4. 配音要点

- 读法：gh 多数地方省略不读（“auth switch 一条命令换号”），PR →“P R”，参数口语化（“加上 clone 参数”）。
- 加了三句（G02_03 切换账号、G03_04 fork、G05_03 issue develop），D05 改成“Issue 怎么办？”；三个种子 ASR 都把 Issue 听成“也许”，以时长和听感为准用默认种子。

## 5. 事实核对（cli.github.com 手册、GitHub Changelog）

- `gh auth switch` 在已登录的多个账号之间切换当前账号（2023-12 起支持多账号）。
- `gh repo fork OWNER/REPO --clone` 复刻 + 克隆，并把原仓库设为 `upstream`。
- `gh issue develop N --checkout` 建一个和 Issue 关联的分支并切过去；PR 合并后 Issue 自动关闭。
- `gh pr merge N --squash --delete-branch`；大部分 `view` / `list` 命令支持 `--web`。
