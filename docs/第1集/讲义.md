# AI娘 Git课 · 第1集讲义：存档、读档、平行世界

> 一句话：**Git 就是给文件夹装上游戏存档系统**——随时存档、随时读档，还能开平行世界。

## 0. 安装与配置（只做一次）

```bash
git version                                   # 能看到版本号 = 装好了
git config --global user.name  "你的名字"
git config --global user.email "you@example.com"
```

## 1. 存档

### 三个区域

```
工作区（正在改的文件） ──git add──►  暂存区（快递箱） ──git commit──►  仓库（永久存档）
```

### 命令

| 想做什么 | 命令 |
|---|---|
| 把文件夹交给 Git 管理 | `git init`（会生成隐藏的 `.git/`，**别删**） |
| 看哪些文件改了 | `git status`（红 = 还没放进暂存区，绿 = 已放进） |
| 看具体改了哪几行 | `git diff` |
| 放进暂存区 | `git add 文件名`，全部放进：`git add .` |
| 存档 | `git commit -m "完成第一章"` |
| 看存档记录 | `git log`，简洁版：`git log --oneline` |

> 存档说明要写清楚“做了什么”，别写“改了改”。

**每天的循环：改文件 → `git status` → `git add` → `git commit`**

## 2. 读档

| 情况 | 命令 | 注意 |
|---|---|---|
| 改崩了，还没 add | `git restore 文件名` | 没存的改动会直接丢掉，找不回 |
| 已经 add 进暂存区 | `git restore --staged 文件名` | 只是拿出箱子，改动还在 |
| 想要某个旧存档里的文件 | `git restore --source=编号 文件名` | 编号用 `git log --oneline` 查 |
| 撤销整个存档 | `git revert 编号` | 不删历史，新建一个“反向存档” |

⚠️ `git reset --hard` 会直接抹掉存档，新手不要用。

## 3. 平行世界（分支）

```
main:  ●───●───●
                └──●───●   idea
```

| 想做什么 | 命令 |
|---|---|
| 开一个新分支 | `git branch idea` |
| 切过去 | `git switch idea` |
| 新建并切过去（一步） | `git switch -c idea` |
| 切回主线 | `git switch main` |
| 把分支合回主线（先切回 main） | `git merge idea` |
| 删掉用完的分支 | `git branch -d idea` |

### 冲突

两条线改了同一句话时，合并会冲突，文件里会出现：

```
<<<<<<< HEAD
主线的写法
=======
分支的写法
>>>>>>> idea
```

解决：自己决定保留哪段，删掉 `<<<<<<<`、`=======`、`>>>>>>>` 三行标记，然后：

```bash
git add 文件名
git commit -m "解决冲突"
```

冲突很正常，别怕！

## 4. 实战：从零完整走一遍

```bash
mkdir 论文 && cd 论文
git init                         # 建仓库
git add .
git commit -m "完成第一章"        # 第一个存档
git switch -c idea               # 开分支并切过去
git add .
git commit -m "尝试新写法"        # 在分支上存档
git switch main                  # 回主线
git merge idea                   # 合并（Fast-forward）
git log --oneline --graph        # 看整条历史
```
