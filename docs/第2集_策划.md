# 第2集《GitHub 云存档》策划案

> 状态：**策划 + 台词初稿**（2026-10-25）。台词的唯一来源是 `ep2/_gen_script.py`，运行后生成 `ep2/script.json`（朗读稿）和 `ep2/subtitles.json`（字幕稿）。
> 沿用第1集定下的规范：4–5 分钟、一问一讲、不来回插话、立绘不抖、结尾固定“复习 → 实战 → 预告 + 三连”。

## 1. 定位

| 项 | 内容 |
|---|---|
| 主线比喻 | Git = 游戏存档 → 本集讲“**云存档**”：存档同步到服务器，换机器也能继续玩 |
| 观众收获 | 能把本地仓库推到 GitHub，换电脑能 clone，两台电脑能用 pull / push 保持同步，push 被拒时知道该怎么办 |
| 讲师 | GitHub娘（本集讲的就是她的“老家”，不轮换）。第3集起再考虑从素材库轮换讲师 |
| 学生 | 大肥鱼（DeepSeek娘形象） |
| 时长 | 台词 73 句（GitHub娘 61 / 大肥鱼 12），中文约 1480 字。按第1集的语速和节奏估算 **约 4 分钟**，加上新场景的动画空拍约 4 分 10 秒 |
| 和上下集的衔接 | 开头接第1集预告“电脑坏了怎么办”；`pull` 冲突直接引用第1集的冲突处理；结尾预告第3集“联机模式：多人协作”，并预埋 `.gitignore` |

## 5. 配音

| 角色 | 方案 | 说明 |
|---|---|---|
| 大肥鱼 | 照旧：GPT-SoVITS v5turbo 零样本，参考音 `audio/ref/` | 12 句，全部没有英文 |
| GitHub娘 | **需要先决定**（见下） | 61 句，按块生成（13 块），每块一条，再用 `cut.py` 切句 |

**GitHub娘音色的一致性风险**：第1集用的是 Arena TTS 的 voice-01，但 Arena 的音色编号只在当次会话有效，新会话里无法保证是同一个声音。两个方案：

1. **推荐：用 GPT-SoVITS 克隆第1集的 GitHub娘**。从 `ep1/vo/G**_**.ogg` 里挑 3–5 句干净、情绪不同的作为参考音（建一个 `audio/ref_g/`），和大肥鱼走同一条管线。以后每集音色都稳定，也不受 Arena 每轮生成条数的限制。
2. 在 Arena 重新试听，选最接近第1集的音色。省事，但两集的声音可能听得出差别。

**读法规避**（朗读稿已按此改写，生成后用 ASR 抽查）：

| 字幕稿 | 朗读稿 |
|---|---|
| `-u` / `-v` / `--oneline` / `--force` | 加 u 参数 / 加 v 参数 / 加 oneline 参数 / 加 force 参数 |
| `README` | read me |
| `.gitignore` | git ignore |
| `origin/main` | origin 斜杠 main |
| `origin`、`fetch`、`rejected`、`ahead`、`behind`、`thesis` | 保持原样，**先试读**；念错再改成谐音 |

## 6. 工程与流水线

1. **目录**：新建 `ep2/`，结构与 `ep1/` 相同（`vo/`、`web/`、`script.json`、`cut.py`）。已有：`_gen_script.py`、`script.json`、`subtitles.json`。
2. **引擎**：
   - 推荐把 `ep1/web/engine.js` 里与集数无关的部分（时间工具、组件、背景、字幕、立绘、音效登记）抽成 `common/engine-core.js`。`ep2/web/engine.js` 只放 `TEXT`、`PLAN`、`CHAP`、`CAMEOS` 和 `SC.*`。
   - 第1集已经定稿，**不改动**，继续用它自己的 `engine.js`。
   - `index.html` 先载入 core，再载入本集脚本。
3. **字幕**：`subtitles.json` 的内容贴进 `TEXT`，或者让 `index.html` 直接 fetch 这个文件。
4. **prep / render / mix / build**：从 ep1 复制。`prep.py` 已支持 `EP_DIR`，`mix.py` 按自身位置找集数目录，不用改。`build.sh` 里只改成片文件名：`AI娘Git课_第2集.mp4`。
5. **片尾曲**：照旧从 `外源/` 读取。发布前确认平台对《花の塔》的版权识别政策；如果要换成免费曲，改 `mix.py` 里的 `SONG` 一处即可。
