# 第4集《Git 后悔药大全》策划案

> 状态：**策划 + 台词定稿**（2026-10-27）。台词的唯一来源是 `ep4/_gen_script.py`，运行后生成 `ep4/script.json`（朗读稿）和 `ep4/subtitles.json`（字幕稿）。
> 讲师 **GitHub娘**，学生 / 组长 **大肥鱼**。AI 分工小队沿用第3集的 6 人，不加新角色；每人对应一个“后悔”场景或一个坑。

## 1. 定位

| 项目 | 内容 |
|---|---|
| 主线比喻 | **Git 药房**：每个“后悔”的场景开一颗药（胶囊），药柜上贴着命令名 |
| 剧情 | 小队继续做《AI娘图鉴》，接连出状况：说明写错、紧急任务打断、提交太碎、`reset --hard` 退过头、看不懂报错 |
| 观众收获 | 会用 `commit --amend` 改说明 / 补文件；会用 `stash` 临时收起改动；分清 `reset` 的 soft / mixed / hard；知道 push 后用 `revert`；会用 `reflog` 找回提交；看懂三条常见报错 |
| 承接 | 第3集预告“Git 后悔药大全”（amend / stash / reset 字卡），本集兑现 |
| 时长 | 60 句、中文 1274 字，按第3集实测（302.5 s / 1490 字 ≈ 0.203 s/字）估算 **约 4分20秒**（含片尾） |
| 结构 | 冷开场 → 片头 → 每颗药一问一讲（一个知识点一次大肥鱼互动）→ 报错急救 → 复习 → 实战 → 下集预告 + 三连 |

## 4. 分镜与画面

沿用第2、3集的终端、浏览器窗口、提交卡片、云朵分支、小贴纸 cameo；说话的小队成员在右侧显示立绘，不说话时缩成小贴纸做反应。新组件：

| 块 | 画面 | 花字 | 新组件 |
|---|---|---|---|
| `cold` | 终端 `git commit -m "2024年更新"`，下一行文件列表里 `photo.png` 灰着（没加进去），红色 × 叠两次 | “Git 有后悔药吗？” | — |
| `title` | 木质药柜，每一格是一颗不同颜色的胶囊：蓝 amend、黄 stash、橙 reset、绿 revert、紫 reflog；最下层一个红色警示瓶 `--hard` | “Git 后悔药大全” | `pharmacy()` |
| `amend` | 蓝色胶囊飞入；提交卡片上的说明被划掉重写，哈希翻牌换新；漏掉的文件飞进同一张卡片；右上角提示“没 push 的才能改” | “第一颗：amend” | `capsule()`、`hashFlip()` |
| `stash` | 千问举扇喊“紧急任务”；工作区的半成品文件卡片滑进抽屉，工作区变空；切到 hotfix 分支修好；回来后抽屉拉开文件弹回；`stash list` 三行 | “先收进抽屉！” | `drawer()` |
| `reset` | 三格（提交 / 暂存区 / 工作区）；豆包的三张碎提交卡被收回到暂存区，合成一张；口诀三行依次点亮 | “soft 留暂存 · mixed 留工作区 · hard 全清空” | `resetBoxes()` |
| `hard` | Grok 回车，提交卡片和工作区一起碎裂；红色警示瓶贴上“危险药品”；revert：历史线末尾多出一个反向箭头的新提交 | “push 过的用 revert！” | `dangerLabel()`、复用历史线 |
| `reflog` | Kimi 捧日记，日记页就是 reflog 列表（`HEAD@{0}`、`HEAD@{1}` ……），第二行发光；编号被复制、贴进 `reset --hard`；碎掉的提交卡片拼回原样 | “Git 的日记：reflog” | `reflogDiary()` |
| `errors` | 三张红色报错卡依次弹出（英文原文），Claude 小贴纸读完后，每张卡翻面露出绿色解法 | “读完再动手” | `errorCard()` |
| `recap` | 回到药柜，每颗胶囊下面贴一行用途 | — | 复用 `pharmacy()` |
| `practice` | 7 步进度条；左侧终端打字，右侧白饭页小窗；最后一步“白饭页一个字都没丢” | “吃了后悔药，一个字都没丢！” | 复用 |
| `teaser` | 下集关键词：`git tag` / `v1.0` 标签 / Releases 页面；三连；署名行 | “给作品打上版本标签” | — |
