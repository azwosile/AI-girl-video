```
刚提交就发现说明写错了、改到一半要切分支、手滑 reset --hard 提交全没了……
这集 GitHub娘 开了一家“Git 药房”，五颗后悔药一次讲全！

00:00 开场：刚提交就后悔了
00:17 amend：改上一次提交（Gemini 又写成 2024 年）
00:48 stash：改到一半先收进抽屉（千问的紧急任务）
01:15 reset --soft / --mixed：撤回提交、合并碎提交（豆包）
01:47 reset --hard 有多危险 + 已 push 用 revert（Grok）
02:17 reflog：退掉的提交找回来（Kimi 翻日记）
02:52 报错急救：本地改动会被覆盖 / detached HEAD / not a git repository（Claude）
03:20 复习速查
03:36 实战：后悔药完整用一遍
04:05 下集预告：git tag 与 GitHub Releases

口诀：soft 留暂存，mixed 留工作区，hard 全清空。
注意：amend / reset 会改历史，只对还没 push 的提交用；已经 push 的用 revert。reflog 只能找回提交过的东西。
```
