## 4. 配音要点

- GitHub娘克隆会把“版本号”读成“版本后”：朗读稿里 G 句一律避开（标题句读作“版本标签与发布”，字幕仍写“版本号与发布”）。
- 版本号读法：`v1.0.1` → “V 一点零点一”；`v2024` → “V 二零二四”。
- 参数读法：“加 a 参数”“加 tags 参数”“加 detach 参数”“加 delete 参数”“加 follow tags 参数”。
- 英文名谐音：Claude → 克劳德（GitHub娘句内）。
- 避开多音字“重”“行”（“重打”改“再打一次”）。
- 每次跑完逐句 ASR 审核（Paraformer + Whisper 交叉）。

## 5. 事实核对

- `git push` 默认不推标签；`--follow-tags` 只推送可达提交上的**附注**标签。
- `git switch --detach <tag>` 进入 detached HEAD；`git switch -c <新分支> <tag>` 从标签开新分支。
- GitHub Releases：按钮 “Draft a new release”、“Generate release notes”、“Set as a pre-release”、“Publish release”；Source code（zip / tar.gz）自动附上；最新正式版显示 “Latest”。
- 语义化版本（semver.org）：MAJOR 不兼容，MINOR 向下兼容的新功能，PATCH 向下兼容的修复；`0.y.z` 为初始开发阶段，随时可能改变。
