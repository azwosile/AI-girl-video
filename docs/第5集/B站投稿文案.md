## 置顶评论（可选）
```
发布三件套一张图记住：
打标签 → git tag -a v1.0 -m "说明"
推标签 → git push --tags（或 --follow-tags）
打错了 → git tag -d + git push origin --delete
版本号 → 修 bug 改末位 / 加功能改中间 / 不兼容改首位
发布 → GitHub Releases：选标签 → 写说明 → 加附件 → Publish
你的“最终版”排到第几了？评论区说说👇 下集用 GitHub Pages 把白饭页变成真网站！
```
