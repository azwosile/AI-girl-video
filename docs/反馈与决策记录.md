## 第1集 v1（4分51秒）→ 反馈

> “每句停顿太长，语速太慢，AI娘抖动太多了，这点内容不能讲这么长时间”

- 语速：GitHub娘 ×1.2，大肥鱼 ×1.1（不变调）；句内长停顿压缩。
- 衔接：句间 0.28–0.5 s → 0.08–0.2 s；章节卡 2.6 s → 1.5 s。
- 立绘：去掉说话时的上下弹跳和换表情时的跳动，只保留慢呼吸；屏幕震动减半。
- 结果：v2 为 3分23秒。

## 第1集 v2（3分23秒）→ 反馈

> “再稍微减少一些衔接，加快一下语速；这章内容太少了，建议把 3 集合成一集；顺便整理一下文档”

- 三集合一：存档 + 读档（restore / revert）+ 平行世界（branch / switch / merge / 冲突）。下集预告改为 GitHub 云存档。

- 语速：GitHub娘 ×1.3，大肥鱼 ×1.15。
- 文档：整理成本 `docs/` 目录。
- 结果：v3 为 4分27秒，-15.8 LUFS（三部分内容）。

## 第1集 v3（4分27秒）→ 反馈

> “可以多生成一点表情差分与动作；大肥鱼有些画面头上没截全；视频最后加一个实战连贯操作；三连与下集预告时插入《花の塔》的开头”

- 头顶被切：原因是大肥鱼差分是横版构图，头饰贴着画面上边。全部改为竖版重新生成，头顶留空。

- 片尾曲：预告 + 三连换成《花の塔》开头，三连画面延长到约 6 秒。
- 结果：v4（见 README）。

## 沿用到后续集数的规范

- 每集 4–5 分钟，一问一讲，不来回插话。
- 字幕写真实命令，朗读稿按 TTS 读法改写。
- 立绘不抖；震动只给冲击镜头。
- 每次出片都做：联系表检查 + 全片 ASR + 响度检查。
- 生图一律竖版并在头顶留空；每轮最多生成 10 张图，批量差分要分轮。
- 每集结尾固定：复习速查 → 实战连贯操作 → 下集预告 + 三连。
