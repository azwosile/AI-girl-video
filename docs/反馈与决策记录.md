## 沿用到后续集数的规范

- 每集 4–5 分钟，一问一讲，不来回插话。
- 字幕写真实命令，朗读稿按 TTS 读法改写。
- 立绘不抖；震动只给冲击镜头。
- 每次出片都做：联系表检查 + 全片 ASR + 响度检查。
- **每次配音或重配后都跑逐句 ASR 审核**（`qa_asr.py`，Paraformer + 拼音比对）；低于 0.85 的句子再用 Whisper 复核英文，确认后才出片。
- **生成立绘后逐张数手**：每个角色只能有两只手，抱玩偶、拿道具的姿势最容易多出一只手。
- 朗读稿要避开多音字误读（如“一行”写成“一航”），英文名在 GPT-SoVITS 里写成中文谐音。
- 生图一律竖版并在头顶留空；每轮最多生成 10 张图，批量差分要分轮。
- 每集结尾固定：复习速查 → 实战连贯操作 → 下集预告 + 三连。
- GitHub娘配音从第2集起固定用 GPT-SoVITS 克隆（参考音 `audio/ref_g/`），保证各集音色一致。
- 新角色第一次出场时就把参考音存进仓库，之后各集都用同一条参考音克隆。
- 豆包以后各集都用自训练模型（`tts_doubao.yaml` + 参考 r19），不再用 Arena 声音。
- 每个客串角色都要对应一个知识点或一个坑，不做纯卖萌的出场。
