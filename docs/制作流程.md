# 制作流程

## 总览

```
脚本 ──► 配音 ──► 切句 ──► prep（提速/压停顿/测时长）──► 引擎排时间轴 ──► 逐帧渲染 ──► 混音 ──► 成片
 script.json   TTS     cut.py      prep.py → durations.json       engine.js        render.py     mix.py    build.sh
```

画面是“时间的纯函数”：`renderAt(t)` 只依赖 t，所以任何一帧都能单独渲染、反复核对。
时间轴由**台词实测时长**自动排出，改一句台词，后面所有动画会自动跟着移动，不需要手动对时间。

## 1. 脚本

- 结构：每个知识点 = 大肥鱼提问 1 句 + GitHub娘连续讲解。不要来回插话。
- 两份文本：
  - `ep1/script.json`：**朗读稿**，送给 TTS。英文命令按 TTS 读法改写（见下方“读法规避”）。
  - `engine.js` 里的 `TEXT`：**字幕稿**，写真实命令（如 `--staged`、`-c`）。
- 大肥鱼的台词尽量**不含英文**（GPT-SoVITS 零样本读 Git 会念错）。

## 2. 配音

| 大肥鱼 | GPT-SoVITS v5turbo 零样本，主机 9880 端口 | 参考音 + 参考文本见下表；seed 1234，speed 1.05–1.1 |

大肥鱼参考音（`audio/ref/`）：

| 文件 | 情绪 | 参考文本 |
|---|---|---|
| dwg_0036 | 慌张 | 别、别突然从后面叫我，我真的会被你吓到。刚才屏幕为什么自己亮了？我明明没有碰它。 |
| dwg_0053 | 思考 | 嗯，让我想想，这件事其实没有你想象中那么复杂。 |
| dwg_0002 | 日常 | 什么嘛，这么简单的事情，你居然专门跑来问我。 |
| dwg_0033 | 无奈 | 你又订阅别的人工智能了？行吧，我就当没看见。 |
| dwg_0031 | 轻松 | 今天的海水温度刚刚好，特别适合一边摸鱼，一边认真工作。 |

调用：`POST http://127.0.0.1:9880/tts`，参数 text、text_lang=zh、ref_audio_path、prompt_text、prompt_lang=zh、speed_factor、media_type=wav、seed。

**读法规避（Arena TTS）**：`HEAD` 会逐字母念，写成 “Head”；`init` 念得像 “he need”，写成 “in it”；参数写成“加 staged 参数”“加 c”，不要写 `--staged` / `-c`。

## 3. 切句

`ep1/cut.py`：faster-whisper（small）做字级时间戳 → 与 script.json 对齐 → 在相邻两句之间找能量最低点切开 → `cut/G05_03.wav` 这样的单句文件。
切完要用 ASR 把每句首尾抽查一遍，确认没切到字。

## 4. prep.py（主机上由 build.sh 调用）

| 参数 | 值 | 作用 |
|---|---|---|
| `TEMPO` | G 1.3 / D 1.15 | 提速，不变调（ffmpeg atempo） |
| `MAX_SIL / KEEP_SIL` | 0.18 s / 0.12 s | 句内超过 0.18 s 的停顿压到 0.12 s |
| 首尾 | 前留 15 ms、后留 60 ms | 裁掉静音 |

输出 `vo48/*.wav` 和 `web/durations.json`（引擎读取它来排时间轴）。

## 5. 引擎 engine.js

文件从上到下依次是：

1. **TEXT**：字幕。
2. **PLAN**：播放顺序。`V(块, 台词ID, 表情)`、`BEAT(块, 秒)`（留给动画的空拍，实际时长 ×0.35）。
3. **节奏参数**：`GAP_SAME 0.04`（同一人连续两句）、`GAP_SWITCH 0.12`（换人）、`GAP_BLOCK 0.12`（换场景）。
4. **时间工具**：`S(id)` 句子开始、`E(id)` 句子结束、`P(id, 0.5)` 句子一半处。动画全部挂在这些时间点上。
5. **组件**：终端（`{y}` `{g}` 等颜色标记，打字机效果）、窗口、文件图标、提交节点、分支图、花字、印章、贴纸等。
6. **场景 SC[块名]**：每块一个函数。提问镜头统一由 `askScene` 绘制，左上角的章节标签来自 `CHAP`。
7. **音效**：每个场景下面用 `SFX_FNS.push(...)` 登记，渲染时导出到 `window.TIMELINE.sfx` 给混音用。

**立绘动作规范**（根据反馈定下的）：不做说话时的上下抖动，只保留很慢的呼吸缩放（±0.3%）；换表情用 0.2 s 交叉淡化；屏幕震动只在冲击镜头用、幅度小。
换到欢呼表情（g_cheer）时轻跳一次（30 px，0.36 s），这是唯一的“跳”动作。

**表情差分**：
- 生图要求：竖版 9:16，**头顶上方留空**（之前横版构图把大肥鱼的头顶和头饰切掉了），纯绿 #00FF00 背景，参考原设定图（GitHub娘：`E:\AI\Opus5.5 video\Ai娘图片\GitHub Copilot.png`；其他角色：素材库 `E:\AI\AI娘课程\ai-girls`）+ 已有差分。
- 抠图：`tools/key.py`（绿幕抠像 → 去溢色 → 白描边贴纸；头顶贴边会给出 WARN）。用法见脚本开头，或 `第2集_策划.md` 第 4.2 节。
- 引擎里 `SPRC` 表给每张竖版图设定“只显示上半身”的比例（头顶到腰），这样全身图和半身图在提问镜头里大小一致。
- 现有：GitHub娘 explain / point / wink / cheer / warn；大肥鱼 panic / curious / happy / raise / think / cry / shock / sparkle / ok / relief。
- `CAMEOS` 表：讲解中的关键时刻，大肥鱼从右下角探出做反应（惊讶、闪亮眼、松口气等）。避开右下角有内容的镜头。

## 6. 渲染与混音

- `render.py`：起本地 HTTP 服务 → Chrome 无头 → 逐帧 `renderAt` → ffmpeg 编码 1080p30。`--sheet` 输出联系表（每句取一帧）用于检查画面。
- `mix.py`：按 timeline 放人声和音效；BGM 自动循环，遇到人声闪避 60%；最后 tanh 软限幅。
- 片尾曲：`外源/さユり - 花の塔.mp3` 存在时，从“下集预告”块开始播放歌曲开头（前奏是满编乐器、无人声），BGM 0.8 s 淡出；有人声时歌曲压到约 45%，片尾 1.5 s 淡出。
- `build.sh` 最后用 loudnorm 统一到 **-16 LUFS / 48 kHz AAC 192k**。

## 7. 质检清单

- [ ] 联系表：逐句看一遍，没有遮挡、出框、文字溢出
- [ ] 全片 ASR：台词齐全、没有吞字
- [ ] 响度 -16 LUFS 左右，峰值不超过 -1.5 dBTP
- [ ] 结尾署名行在
- [ ] 新增花字的汉字已重新子集化字体（否则会显示成系统字体）

## 改台词 / 加段落

1. 在 `script.json` 加朗读稿，在 `engine.js` 的 `TEXT` 加字幕。
2. 生成配音 → 切句 → 放进 `ep1/vo/`。
3. 在 `PLAN` 里插入 `V(...)`；如果是新场景，写 `SC.新块名` 和对应的 `SFX_FNS`。
4. 花字有新汉字时重新子集化：从 engine.js 里提取所有引号内的文字 → `pyftsubset … --text-file=chars.txt --flavor=woff2`。
5. `./build.sh`。

## 常见坑

- 主机路径含中文，ffmpeg 输出文件名在终端里会显示成乱码，但文件本身是正常的。
- GPT-SoVITS 冷启动要 2 分钟以上，先访问一次确认它在线（返回 404 也算在线）。
- loudnorm 不加 `-ar 48000` 会输出 96 kHz。
- 主机访问不了 huggingface.co，要用 hf-mirror.com。
