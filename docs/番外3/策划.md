## 4. 配音要点

- 读法：VS Code →“V S Code”；界面按钮读中文（“暂存所选范围”“放弃更改”“完成合并”）。
- 加了两句（G02_04 放弃更改、G03_03 取消暂存），审核相似度 1.0 / 0.86（“减号”被听成“检后”，听感正常）。

## 5. 事实核对

- VS Code 源代码管理：M 修改、U 未跟踪、D 删除；“暂存所选范围”（Stage Selected Ranges）可以只暂存选中的行；“放弃更改”会丢掉工作区改动。
- 冲突块上方的 CodeLens：Accept Current / Incoming / Both；“在合并编辑器中解决”打开三栏合并编辑器，“完成合并”后再提交。
- GitHub Desktop 官方免费（Windows / macOS）。
