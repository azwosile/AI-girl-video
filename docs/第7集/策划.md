## 5. 事实核对（docs.github.com，2026-10）

- 工作流文件放在仓库的 `.github/workflows/` 目录，扩展名 `.yml` 或 `.yaml`；提交后按 `on` 里的事件触发，在 Actions 标签页查看：工作流 → 某次运行 → 任务 → 展开步骤看日志。
- `actions/checkout` 当前最新是 v7（2026 年 7 月发布）。
- GitHub 托管的标准运行器在公开仓库免费；私有仓库 Free 账号每月 2000 分钟，Pro / Team 3000 分钟。
- `pull_request` 触发后检查结果显示在 PR 页面；`workflow_dispatch` 会在 Actions 页面出现 Run workflow 按钮（工作流文件要在默认分支上）。
- `schedule` 用 POSIX cron，默认 UTC；2026-03 起可以在 `cron` 旁边加 `timezone:`（IANA 时区名）。最短间隔 5 分钟；高负载时（尤其整点）可能延迟甚至丢弃；只在默认分支上运行；公开仓库 60 天没有活动会自动停用定时工作流。
- 仓库密钥：Settings → Secrets and variables → Actions → Secrets → New repository secret；工作流里用 `${{ secrets.NAME }}` 引用，日志里自动打码成 `***`，保存后看不到原值。
- 状态徽章地址 `https://github.com/OWNER/REPO/actions/workflows/FILE.yml/badge.svg`；界面入口：工作流页右上角 ⋯ → Create status badge。
