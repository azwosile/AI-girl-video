## 5. 事实核对

- 提交邮箱要和 GitHub 账号里验证过的邮箱一致，提交才会关联到账号、显示头像。
- 不加 `--global` 的 `git config` 写入当前仓库的 `.git/config`，只在这个仓库生效。
- `git diff` 比较工作区和暂存区；`git diff --staged`（同 `--cached`）比较暂存区和最新提交。
- `.gitignore` 只对未跟踪的文件起作用；`git rm -r --cached <路径>` 只从索引里删除，工作区的文件保留。
- `git check-ignore -v <文件>` 会输出是哪个文件的哪一行规则让它被忽略。
- GitHub 新建仓库时可以选“Add .gitignore”模板（Node、Python 等）。
