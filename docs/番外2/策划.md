## 5. 事实核对（docs.github.com）

- GitHub 不再接受账号密码做 Git 操作：HTTPS 用个人访问令牌（PAT），或改用 SSH。
- `ssh-keygen -t ed25519 -C "邮箱"`；`ssh -T git@github.com` 首次连接要确认主机指纹，成功会显示 `Hi 用户名!`。
- 同一把公钥不能加到两个账号（`Key is already in use`）；多账号官方方案之一就是每个账号一把钥匙 + `~/.ssh/config` 的 Host 别名。
- `includeIf "gitdir:~/work/"` 按仓库所在目录加载另一份配置（结尾的 `/` 表示包含子目录）。
