## 4. 配音要点

- 读法：feat / fix / docs 按英文读，“五十个字符”读中文；`--grep "^fix"` 字幕保留，朗读口语化。
- 逐句审核：D06“白饭页”默认种子听成“白饭叶”，重做两个种子用 4321（相似度 1.0，记在 `SEED_OVERRIDE`）。

## 5. 事实核对

- 约定式提交（conventionalcommits.org）：`类型(范围): 描述`，`!` 或 `BREAKING CHANGE:` 表示破坏性改动。
- `commit-msg` 钩子的第一个参数是提交说明文件路径，非零退出会中止提交；`pre-commit` 在写说明之前运行。
- `.git/hooks` 不随仓库克隆；`git config core.hooksPath <目录>` 指定钩子目录，脚本需要可执行权限。
- `git commit --no-verify` 会跳过 pre-commit 和 commit-msg。
